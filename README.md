# Zenith Type Foundry

High-fidelity digital type foundry specializing in high-performance retail and custom typefaces.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Lucide React

## Features
- **Font Testing**: Real-time type testing with variable font controls.
- **Comparison Mode**: Compare multiple fonts side-by-side.
- **Poster Studio**: Create and download custom posters using Zenith fonts.
- **Opentype Controls**: Fine-tune ligatures, kerning, and stylistic sets.
- **Mobile Responsive**: Optimized for all devices.

## SEO & Technical
- `robots.txt` & `sitemap.xml` configured.
- JSON-LD structured data for search engines.
- OpenGraph & Twitter Card support.
